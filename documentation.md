# Portfolio Documentation

## Introduction
Welcome to the documentation for my personal portfolio! This project serves as a comprehensive digital resume, showcasing my technical skills, professional experience, and web development projects. It is designed to offer a clean, interactive, and responsive experience for all visitors, demonstrating my capabilities in building modern web applications.

## Overview
This portfolio is a dynamic Single-Page Application (SPA) built using React.js and styled with Tailwind CSS. It features a scalable, component-based architecture with interactive UI elements, smooth transitions, and a unique developer-centric "Terminal" interface. The content, including education and professional experience, is rendered dynamically from data arrays to simplify maintenance. 

**AI Integration**: During the development process, Advanced AI assistants (like Google's Gemini) were utilized to accelerate development, implement complex UI animations (such as the interactive background), and refine the overall codebase architecture.

You can view the live site here: **[https://www.swasthik-nj.me/](https://www.swasthik-nj.me/)**

## Components Used
The portfolio relies on a variety of reusable and interactive components:
- **Home Component**: Serves as the landing page, integrating profile information, a dynamic background, and entry points to the rest of the application.
- **CareerShell (Terminal)**: A custom-built, interactive command-line interface that allows users to explore the portfolio using terminal commands.
- **Background Boxes**: An animated, grid-based background component powered by Aceternity UI and Framer Motion, providing a modern, sleek aesthetic.
- **Navigation & Routing Components**: Built on top of React Router DOM, ensuring seamless, client-side page transitions.

## Key Features
- **Interactive Terminal Interface**: A standout feature of this portfolio is the `CareerShell` component. Accessible via a keyboard shortcut (`Ctrl + \``) or an on-screen button, it simulates a developer's terminal environment, allowing visitors to type commands and navigate the portfolio interactively.
- **Responsive Design**: The layout adapts seamlessly to all screen sizes, from mobile devices to large desktop monitors, ensuring a consistent user experience.
- **Dark/Light Theme Toggle**: A built-in theme switcher allows users to choose their preferred viewing mode. The choice is saved locally to persist across sessions.
- **Single-Page Application (SPA)**: Powered by React Router DOM for instant, seamless navigation without page reloads.
- **Dynamic Content Rendering**: Sections like Education, Experience, and Projects are driven by structured data, making updates effortless.

## 🛠️ Technologies Used
- **Frontend Framework**: React.js
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **UI Components**: Framer Motion, Aceternity UI
- **Icons**: React Icons, Google Material Symbols
